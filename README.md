# Título

Trivia Game 🧩

# Descripción

Trivia Game es una aplicación desarrollada en Java utilizando Spring Boot que permite gestionar y jugar partidas de preguntas y respuestas. 
El proyecto implementa conceptos de programación orientada a objetos, persistencia de datos y arquitectura por capas para ofrecer una experiencia de juego dinámica y escalable.

## 🛠️ Información Técnica

##### Tecnologías utilizadas

* Java
* Maven
* Spring Boot
  * módulo jpa
  * módulo web
  * módulo security
* Boostrap / HTML5 / JQuery


##### Pre-requisitos

Crear un base de datos utilizando los scripts provistos en el proyecto
Configurar el archivo application.properties con los datos de conexión a la base de datos


##### Instalación

Una vez decargado el proyecto, elecutar los comandos
```
>mvn clean install
>mvn eclipse:eclipse

Correr el proyecto
```
